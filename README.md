# Synapse Arcade

An adaptive brain-training game that runs in the browser. Seventeen rooms, each tracking its own difficulty (1–10) and tuning itself so you succeed about 75% of the time.

| Wing | Room | What you learn |
| --- | --- | --- |
| Explorers | **World Kitchen**: guess where a dish comes from on a world map (plus a 60-second Blitz). Workshop: build the plate from real ingredients and trace where each came from. Every explorer game has a lobby with a collection book, coins and a daily workshop | Geography, food history |
| Explorers | **Time & Thread**: guess where and when an outfit was worn. Workshop: era runway, putting outfits in order on a timeline. Every explorer game has a lobby with a collection book, coins and a daily workshop | History, geography |
| Explorers | **Landmark Hunt**: pin 32 illustrated world landmarks on the map. Workshop: postcard tile puzzle. Every explorer game has a lobby with a collection book, coins and a daily workshop | Geography, history |
| Explorers | **Atlas Detective**: an unlabeled map: find countries, name highlighted ones by shape, pick capitals (64 countries). Workshop: border jigsaw with real country shapes. Every explorer game has a lobby with a collection book, coins and a daily workshop | Map reading, capitals |
| Explorers | **Earth Detective**: real photos of 24 places from around the world (rice terraces, oases, fjords, deltas, reefs, glaciers, rifts). Pick the clues you can actually see, reason out the climate zone, pin the place on the map, then learn why it looks like that. Each place adds a geography concept to your field notebook (monsoon, rain shadow, fjords, continentality, plate boundaries and 16 more), and known concepts return as quick recall questions. The original Postcard Trip is a classic mode | Physical geography, climate, landforms |
| Explorers | **Mystery Guest**: a silhouette from history; reveal clues and guess who it is (43 figures). Workshop: interview the guest while their portrait comes into focus. Every explorer game has a lobby with a collection book, coins and a daily workshop | History |
| Explorers | **Flag Maker**: rebuild 59 countries' flags across 10 layouts (stripes, crosses, saltires, triangles, discs). Workshop: design a flag for a client country using real flag-design rules. Every explorer game has a lobby with a collection book, coins and a daily workshop | Flags, symbolism |
| Explorers | **Then & Now**: slot 80 events, from farming to the Webb telescope, into a growing timeline. Workshop: link events into cause-and-effect chains. Every explorer game has a lobby with a collection book, coins and a daily workshop | History |
| Studios | **Test Kitchen**: run a kitchen: tickets with a dish photo, real knife work, a live stove where food browns, sizzles and burns, flipping, stirring, salting pasta water, tasting and seasoning, plating to the photo, coins, upgrades and a daily dish. Classic mode: cook for customers who taste and react ("too salty!") until you get it right | Flavor balance, food science, food origins |
| Studios | **Atelier**: run a styling studio. Dress a live model from a wardrobe rack to a client's mood board, choose fabrics, dye each piece on a color wheel that names the harmony, accessorize, then walk the runway for three judges. Coins, upgrades and a daily look. Classic design mode kept | Color theory, proportion, dress codes |
| Studios | **Hair Salon**: a cut school built on real cutting theory. Lift each section of simulated hair to an angle (its elevation) and cut along a line: 0° gives a one-length weight line, 45° stacks graduation, 90° gives even layers and 180° makes long layers. Turn the head to check the side, front and back, and use quick-angle buttons. Seven short lessons (blunt bob, graduated bob, layered shag, long layers, blunt bangs, curtain bangs, curly hair that shrinks as it dries), each with the idea, a guide line and section-by-section feedback on angle and length, then a salon floor where clients only bring a photo and you work out the technique. Side and front views in its own soft, dark salon style. The full appointment (wash, cut, color, dry, style) is still there as a second mode | Haircutting technique, geometry of angles |
| Studios | **Makeup Studio**: run a makeup studio with real layered painting on a canvas. Clients bring a photo and real skin needs (shine, redness, dark circles, spots, dry patches): prep, color-correct, match foundation shade and undertone, sculpt, paint eyes with close-up zoom and lips, blend and set, scored pixel by pixel against their photo, with coins, upgrades and a daily challenge. Classic and theme modes still paint 17 products onto varied faces (9 skin tones, eye, nose, lip and brow shapes, freckles, vitiligo, mature skin, headscarves, piercings) with brush size, intensity, softness, finish and a blending tool, for 15 occasions or 17 themes | Color theory, skin undertones, makeup history |
| Studios | **Nail Salon**: give real manicures on a lifelike hand. Sanitize first, wipe off chipped old polish, push back cuticles, pick the shape (round, square, squoval, oval, almond, coffin) and file each nail to length in one direction, then base coat, two thin coats of color (painting over a wet coat smudges), clean-up of polish on the skin, French tips, dots, glitter or rhinestones, and a top coat that caps the free edge. Some clients have a sore, swollen nail fold to spot and skip. Eight looks, scored against the client's photo, with coins, upgrades and a daily client | Nail care, hygiene, nail art |
| Studios | **Sewing Room**: run a tailoring studio: measure varied bodies with a tape, choose fabric within budget, lay out, pin and cut the pattern with shears, drive a pedal-powered machine along the seam guide with backstitching, fit and alter on the client, press, hem and close, then walk the runway against their sketch, with coins, upgrades and a daily challenge. Classic mode: take a commission, design it (12 materials, prints, bodice, sleeves, skirt, layers), set up the machine, lay out and sew 30 garments (from tote bags to corsets, ballgowns and waistcoats), then hands-on finishing (boning, grommets, lacing, zippers, embroidery, hem pinning, drawstrings, buttons, pleats, gathering, pressing) and trims | Materials, construction, spatial planning |
| Studios | **Floorplan Lab**: run a home-design firm. Families bring a wish list and a budget: draw rooms, add doors (wide ones for wheelchairs) and windows, furnish with real-size furniture and clearances, pick floors and paint, follow the sun, see it as a 3D dollhouse, then watch them move in. Classic plan mode kept | Spatial reasoning, area, building basics |
| Studios | **Gift Detective**: scroll a person's feed and pin clues, DM their friends, shop on a budget, wrap it by hand, write the card and watch them unbox it. Holiday rush mode shares one budget across three gifts. Classic blog shopping kept | Reading comprehension, inference, empathy, budgeting |
| Studios | **Peacemaker**: mediate a live argument between animated characters whose body language shifts with their mood. Reply before the timer runs out, pick a tone (calm, warm, firm) and words, rescue walkouts and reach one of three endings. Classic scenes kept | Conflict resolution, psychology |
| Brain gym | **Deep Dive**: two versions. Classic: name as many as you can; rare answers sink you deeper. Rare Pick: one answer per category, so pick the rarest you dare. An animated ocean depth chart fills with creatures as your record dive gets deeper. Level map with stars, personal leaderboard and a daily level | Knowledge breadth, recall |
| Brain gym | **Science Lab**: find organs and bones, mix light versus ink, sink or float, line up the planets. Circuit lab: 10 levels of rotating wires to close a circuit. Level map with stars, personal leaderboard and a daily level | Biology, color science |
| Brain gym | Echo Grid, Quick Sums, Unscramble, Switchboard | Memory, mental math, vocabulary, logic |

There's also a daily **World Tour** event (the same five map rounds for every player, with a shareable score) and a **Daily Mix** of eight interleaved questions.

Double-click any word in the app for a definition (built-in glossary, with a dictionary lookup as a fallback). Map rounds show country names as you zoom.

## Project layout

- `src/game.html` is the source: the whole game (HTML, CSS, JavaScript and map data) in one file.
- `scripts/build.py` wraps it into a full web page at `index.html`, which Vercel serves. Run `python3 scripts/build.py` after editing the source, and commit both files.
- Progress is saved in the browser's `localStorage`, so it stays on that device.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy to Vercel

1. Go to <https://vercel.com/new> and sign in with GitHub.
2. Import the `braineeack` repository.
3. Leave **Framework Preset** as **Other**, and leave the build command and output directory empty.
4. Click **Deploy**.

Every push to `main` then redeploys automatically.

## Across the arcade

- **Shared wallet**: one coin balance used by every shop.
- **Less repetition**: rooms remember what you have seen recently across sessions, Peacemaker has 22 scenes, Deep Dive 32 categories, and the explorer rooms draw from every difficulty tier you are ready for.
- **Daily goals**: three new goals every day on the home screen (a wing of the day, variety, the Daily Mix or a room you have never played), with coins for each and a bonus for all three.
- **Streaks**: playing any room counts. A 7-day strip shows your week, and 3, 7, 14 and 30-day streaks pay coin rewards.
- **Jump back in**: one tap returns you to the last room you played.
- **Sticker book**: 27 achievements with unlock toasts.
- **Settings**: sound volume, generated background music, reduced motion, bigger buttons and high contrast.
- **Leaderboards**: on claude.ai, top scores for every studio across everyone the arcade is shared with.
- **Tutorials**: a spotlight tour the first time you open each rebuilt studio.
- **Saves**: all studio progress, coins, stickers and settings now survive a page reload.
